# Marine Weather

Android app for marine planning: multi-source weather on a map, storm radar, and premium route planning (`fi.veneappi.app`).

## Build

```bash
./gradlew assembleDebug          # development
./gradlew bundleRelease          # Play upload (requires keystore.properties)
```

See [docs/PUBLISHING.md](docs/PUBLISHING.md) for Google Play checklist, privacy policy, and store listing text.
