# Venekerhot — yhteystiedot (markkinointi)

**Lähetä vain yleisiin kerho-osoitteisiin.** Älä käytä henkilökohtaisia gmail/outlook-osoitteita massaviestintään.

**Laajenna lista:** [SPV seurakartta](https://spv.fi/kartta/) → vesistö → kerhon sivut → Yhteystiedot.

## Käytännön vinkit

1. **Aloita 5–10 kerhosta** samalta alueelta (esim. Espoo + Helsinki satamat).
2. **Yksi viesti per kerho** — pohja: [sahkoposti-venekerho-pohja.md](sahkoposti-venekerho-pohja.md).
3. **Liitä A4-PDF** — [ilmoitustaulu-marine-weather.html](ilmoitustaulu-marine-weather.html) → Tulosta PDF.
4. **Kirjaa vastaukset** yllä olevaan seurantataulukkoon.
5. **Älä lisää** vastanneita henkilöitä uutiskirjelistalle ilman lupaa.
