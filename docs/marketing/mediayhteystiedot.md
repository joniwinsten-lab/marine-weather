## Työnkulku

1. Tallenna esittelykuva PNG: [totalvene-esittelykuva.html](totalvene-esittelykuva.html) → selain → tallenna kuva.
2. Avaa [sahkoposti-media-pohja.md](sahkoposti-media-pohja.md) → valitse oikea osio.
3. Lähetä **yksi viesti per kohde** (ei BCC-listaa eri lehtiin).
4. Kirjaa päivämäärä seurantataulukkoon.
5. Venemestari + Totalvene: älä lähetä identtistä tekstiä molempiin ilman mainintaa.
