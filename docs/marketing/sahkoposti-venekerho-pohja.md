# Sähköpostipohja — venekerhoille (FI)

Lähetä **yksi kerho kerrallaan**. Liitä [ilmoitustaulu-marine-weather.pdf](ilmoitustaulu-marine-weather.pdf) tai tulosta HTML → PDF itse ([ohje](README.md)).

---

## Aihe (valitse yksi)

```
Marine Weather — ilmainen merisää-sovellus jäsenille (puhelin & tabletti)
```

```
Ehdotus ilmoitustaululle: Marine Weather -sovellus Itämerelle
```

---

## Viesti (copy-paste)

Korvaa `[Kerhon nimi]` ja `[Sinun nimi]` ennen lähetystä.

```
Hei [Kerhon nimi],

Olen [Sinun nimi], Marine Weather -sovelluksen kehittäjä. Kirjoitan
lyhyesti, koska sovellus voi olla hyödyllinen kerhon jäsenille Suomenlahden
ja Itämeren suunnitteluun.

Marine Weather on Android-sovellus (puhelin ja tabletti), jossa näet:

• Kartta ja kolmen lähteen säävertailu (FMI, SMHI, MET Norway)
• Sadetutka ja merisää
• Ilmaisena — reittisuunnittelu, AIS ja offline ovat Premium-vaihtoehtoja Playssa

Sovellus on suunnitteluapu; se ei korvaa virallisia merikarttoja tai
säännöksiä.

Löydät sovelluksen Google Playstä:
https://play.google.com/store/apps/details?id=fi.veneappi.app

Liitteenä on A4-tuloste, jonka voitte halutessanne kiinnittää kerhon
ilmoitustaululle (QR-koodi vie suoraan Playhin). Jos tämä ei sovi
tiedottamiseen, vastaa vain "ei kiitos" — emme lähetä jatkoa.

Ystävällisin terveisin,
[Sinun nimi]
Marine Weather
https://safelight.fi/marine-weather/
```
