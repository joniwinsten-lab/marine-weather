## Tulosta ilmoitustaulu (A4 PDF)

1. Avaa [ilmoitustaulu-marine-weather.html](ilmoitustaulu-marine-weather.html) selaimessa.
2. **Tulosta** → paperikoko **A4**, **Pysty**.
3. Marginaalit: **Oletus** tai **Minimi**.
4. Kytke päälle **Taustakuvat** (background graphics).
5. Valitse **Tallenna PDF:ksi** ja liitä sähköpostin liitteeksi.

QR-koodi osoittaa: `https://play.google.com/store/apps/details?id=fi.veneappi.app`

Kuvat: `../website/assets/` (sama QR kuin verkkosivun esitteissä).

## Työnkulku — mediat

1. Tallenna PNG: [totalvene-esittelykuva.html](totalvene-esittelykuva.html).
2. Lähetä yksi viesti per kohde ([pohja](sahkoposti-media-pohja.md), [yhteystiedot](mediayhteystiedot.md)).
3. Kirjaa lähetys seurantataulukkoon.

## Työnkulku — venekerhot

1. Valitse 5–10 kerhoa listasta (sama vesistö / alue).
2. Lähetä yksi viesti per kerho ([pohja](sahkoposti-venekerho-pohja.md)).
3. Liitä PDF tai tulosta ja vie satamaan, jos kerho vastaa myöntävästi.
4. Merkitse lähetetty / vastaus / ilmoitustaulu listaan.

**Älä** lähetä massabcc:tä henkilökohtaisiin gmail-osoitteisiin. Käytä kerhon `info@` / `toimisto@` / `sihteeri@`.
