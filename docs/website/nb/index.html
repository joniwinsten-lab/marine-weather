Planlegg Østersjøturer med ett kart, tre værtjenester og verktøy for svakt signal til sjøs

Marine Weather kombinerer åpne sjøkart med prognoser fra MET Norway, SMHI og FMI — stormradar, lyn, nasjonale sjøværttekster, premium ruteplanlegging med AIS-fartøy og offline-rutepakker du kan laste ned i havn før avreise.

  • Sammenlign vind nå og +3 / +6 / +12 t på ethvert punkt på kartet
  • Traficoms planleggingskart med MapLibre
  • Tydelig status når data er offline, cachet eller gammel
  • App på engelsk, finsk, svensk og norsk bokmål

Kun planleggingshjelp — erstatter ikke offisielle kart, sertifisert AIS-utstyr eller regler.

Hva appen gjør

Kart og vær

Trykk lenge på kartet for å velge punkt. Se vind, retning og vindkast fra tre modeller. m/s eller knop. Prognoser lagres på enheten — siste vellykkede henting vises også uten nett.

Stormradar og lyn

Animert regnradar og lynnedslag fra åpne data (FMI, MET Norway, SMHI). Tidslinje. Krever nett under visning.

Sjøværttekst (4 land)

Korte sammendrag for Norge, Sverige, Finland og Estland ved kartets midtpunkt, med lenker til fullstendige prognoser.

Ruteplanlegging Premium

Tegn rute, sett fart og sammenlign vær ved fire punkter langs sporet. Eksporter GPX eller PDF-plan.

12-dagers vind Premium

Daglig vindsammenligning fra MET Norway, SMHI og FMI for lengre planlegging.

AIS-fartøy Premium

Fintraffic Digitraffic-fartøy på kartet (Kart og vær og Rute). Trykk for hastighet, kurs og detaljer. Live-data — krever tilkobling.

Offline-rutepakke Premium

I havn med Wi‑Fi: last kartfliser og prognoser langs ruten (~25 nm mellom, alle tre kilder). AIS og radar krever nett.

Tilkobling og dataalder

Banner viser offline, cache eller gammel prognose (6 t / 12 t).

Ingen konto

Gratis funksjoner uten innlogging. Posisjonen blir på enheten. Premium via Google Play.

Til sjøs og tregt nett

Mobildekningen på Østersjøen er ujevn. Forbered i havn og bruk planleggingsdata når lenken faller bort — appen er ikke en full offline-plotter.

Automatisk prognose-cache

Vellykkede hentinger lagres. Ved nettverksfeil vises siste prognose med tidsstempel.

Statusbanner

Se med en gang: ikke nett, cache brukes, prognose kan være gammel eller alle kilder feilet.

Last rute offline Premium

Når ruten er klar, trykk Last offline med Wi‑Fi. Kartfliser og vær langs sporet hentes på forhånd.

Offline-pakke er planleggingshjelp. Live AIS, radar, lyn og sjøtekst krever tilkobling. Ha alltid offisielle kart og utstyr.

Skjermbilder

For liggende Android-nettbrett (minst 600 dp bredde).
