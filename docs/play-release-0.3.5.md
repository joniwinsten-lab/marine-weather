## Release notes — English

```
What's new in 0.3.5

• Track (Seuranta) — new Premium tab: follow vessels you choose (MMSI watchlist, up to 50). Search nearby ships or by name/MMSI, add to your list, see them on the map with live AIS updates.

• AIS map overlay — smoother live movement (2 min course vector), faster refresh when you pan the map (phones and tablets).

• Shared live AIS stream — map overlay and Track tab use one connection for better battery use.

Free unchanged: map & weather, rain radar, marine weather.
Premium: route planning, 12-day wind, AIS, Track tab, offline route pack.

Planning aid only — not for primary navigation.
```
